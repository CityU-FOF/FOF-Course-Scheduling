# FOF Academic Planner v3.4

澳門城市大學金融學院排課工作台。每週固定課表、完全離線、資料保存在本機瀏覽器。v3加入禁排限制、教室容量、假期撞課及全新簡潔介面。

**下載完整ZIP、解壓後開啟 `index.html`；保留同資料夾所有程式檔及vendor資料夾。** 日常使用不需要安裝Node或連接伺服器。請先在舊版備份JSON，再在新版按「還原」。支援原版、v2、v3.0及v3.1備份。v3.1備份使用格式版本4，舊程式會拒絕讀取，以免靜默丟失假期結束日期。請先備份再更新。

## v3.4更新（本版現行規則）

- 考核形式按科目編號統一所有班級／年級／課程。輸入已有科目編號可沿用設定；修改一班會同步同科其他班。若舊資料存在不同形式，工作台提示逐科核對；不會任意選一個覆蓋。涉及鎖定課節時先解鎖。
- **常規排課期間與教學核算分開**：開卷／閉卷常規課表14週，期間仍提早一週結束；教學時數包含考試週的一堂，按學期設定週數（預設15）核算。報告／論文同樣按完整學期核算，合班各班相加。每週2節×75分鐘×15週÷50分鐘＝45學時。
- 學期新增「初期時間規劃」／「教務處指派／選科後核對」階段。初期人數與一般課室可留空，只先填指定實驗室／電腦室；不會因只登記幾間指定教室而把其他未指派課堂全部判成資源不足。已知座位超容量仍會提示。
- 「教室資料 → 匯入選科系統Excel」本機分析`.xlsx/.xls`，依科目編號、課程、年級及名稱班別配對已有科目；確認預覽後更新人數、課室及勾選的容量，**不移動星期／時間、不新增課節、不修改教師或必選修性質**。
- 正選人數＝主班＋跨課程併班；忽略名額、保留／等待人數。重複匯入取代現有值，不會累加；0人與未填分開。跨課程不新增一班或增加教學時數，備份保留本班／跨課程人數拆分。
- 多課室沒有逐節對應時，須在預覽逐時段選擇。來源時段與本系統不同的課節保留原課室；待排課節在單一課室來源時可補上，多課室則待排入相應時間後再匯入。既有容量與來源不符預設不覆寫；多課室共用一個容量值不推斷到每一間。
- 來源總碼班次與名稱班別不一致、非常見跨課程科目等標示人工核對，預設不勾選；未能配對可在同科目編號內手動選班。主班缺漏、正選人數缺漏、跨課程時間／教師／課室與主班不同等來源錯誤不自動匯入。
- **備份格式6**，可讀原版至v3.3；新版備份請用v3.4還原。更新前保留原JSON。原始選科表不會存入公開倉庫或傳送到外部。

[選科匯入操作及配對規則](docs/ENROLMENT-IMPORT.md)。本輪僅完成排課功能；考試座位表／簽到表整合待確認後另做，未自動建立考試。

## v3.3更新（歷史；核算及考核同步以v3.4規則為準）

- 主介面改用金融學院綠、白、金。科目卡白底留白，只在邊線／標籤使用課程分類色；壓力顏色保持綠／黃／紅／藍。課表可留空，沒有填滿要求。
- 建立科目必選開卷考試／閉卷考試／報告/論文，可設學分（預設3）、必修／選修及開課學院／部門（預設金融學院）。共同科目資料在編輯時套用到同課程、同年級、同班、同科目的全部課節；鎖定課節需先解鎖。
- 開卷／閉卷最多14週，報告／論文最多15週，不超過學期設定週數。教學時數按各科週數加權，合班各班繼續相加；第15週考試沒有自動生成為排課或教學時數。
- 上課日期由學期起訖及設定週數決定：結束日向前扣除少上的完整週數。標準15週學期2026-08-24至2026-12-04，考試科為2026.08.24-2026.11.27；報告／論文科至2026.12.04。請先核對學期週數與校曆，假期不延後結束日。假期撞課亦依各科結束日裁切。
- 外院課：建立時仍選學生所屬課程、年級及班別，把「開課學院」填為「通識教育部」或其他部門。所有課程保留班級／教師／教室撞堂及禁排檢查；只有金融學院（或FOF）開課列入本院教學時數及容量壓力。外院課不受本院容量人數阻擋，不代表已核實外院教室容量。
- Excel「排課明細」固定A–I：科目編號、科目名、學分、必修/選修、班級、星期、時間、課室、上課期間。星期用中文，省略節次；同日時間用`; `連接，完全相同時間組合的不同星期用`、`連接。不同教師、課室、學期、課程班級或科目資料不混合，避免產生不存在的星期／時間組合。外院課一併列出。
- 新增「科目資料」工作表供核對教師、開課學院、考核、學分、性質及統計範圍；其他統計及跟進表保留。
- **備份格式升為5**，可讀原版／v2／v3.0／v3.1／v3.2。舊資料的考核形式標為「未設定」、保留原學期週數；學分3、必修、金融學院為待核對預設。請逐科補填考核及外院歸屬。v3.2及以前不能讀新版備份，請保留更新前JSON。

## 建議操作順序

1. 「學期設定」：填學期名稱、起訖日期、核算教學週數及每學時分鐘。
2. 初期選「時間規劃」階段，只先登記指定實驗室／電腦室；一般課室及人數留空亦可。
3. 建立科目及設定考核形式，先排星期／時間。教務處指派及選科後，到「教室資料」匯入選科Excel，預覽後補入人數與課室；亦可手動填寫。
4. 「排課限制」：選教師／全院／課程／班級／教室，勾選每週禁排格。星期標題可選整天，節次標題可選整週該節。
5. 「排課工作台」：拖曳課節到時間格，或先點卡片再點時間格。拖回待排池或 × 可取消安排。待排池 × 會刪除課節；均可撤銷。
6. 「教室容量壓力」：點某星期／節次，查看各教室座位需求、未知資料、禁用或撞堂。合班座位按各班人數相加。
7. 「假期與補課」：載入澳門2026/2027公眾假期，或匯入CSV／ICS；先預覽、按校曆勾選，再加入。
8. 檢查假期撞課，記錄「待跟進／已安排／無須補課」及備註。此為跟進紀錄，不會自動安排或檢查補課時間。
9. 「列印/PDF」選班級或教師。A4橫向；關閉瀏覽器頁首／頁尾，建議開啟背景圖形。
10. 定期匯出JSON備份。Excel是報表，不能還原所有設定及跟進資料。

## 本版核算口徑：合班各班相加

- 教學統計按**班級節次**計算名義學時。即使同時段合班，教師各班學時仍累加。
- 預設每節75分鐘、15教學週、每學時50分鐘：每週2個班級節次＝45名義學時／學期、37.5按班鐘點小時。
- 兩班同時各1節合班，也按2個班級節次核算；「實際課堂」欄才把此合班計一次。
- 「總學時」＝已排班級學時＋待排班級節次推算，合班不扣重疊。
- 核算週數由學院設定，預設15週，包含考試週。考試科常規排課14週，不減少核算時數；學期起訖日期不自行換算核算週數。
- 假期影響另列，**不自動扣除名義學時**，亦不表示實際完成授課時數。

## 功能邊界

- 固定7天×8個75分鐘節次；不設單雙週。
- 新排課／移動阻擋班級、教師、已填課室撞堂、禁排時段及已知超容量。
- 既有資料因新限制、容量調低或導入正選人數變成違規時，保留課表並列入「排課待檢查」，不自動移除。
- 確認合班須同教師、同科目編號及名稱、同課室、同時段、不同班級。移動已合班課請先逐班移回待排池後重排。
- 未填課室、未登記容量或人數未知時，不宣稱資源足夠；已知人數已超容量仍會阻擋。
- 教師以完整一致姓名識別；每節一位教師。尚無設備類型、跨班選修學生、跨校區交通及全局自動求解器；本版的候選建議不會自動改動課表。
- 撤銷／重做50步，只在本次開啟期間有效，包含規則、容量、假期及跟進修改。

## 假期匯入

內置2026及2027澳門**正式公眾假期**，來源為澳門政府入口網站，核對於2026-10-21。沒有預設加入公務員補假或下午豁免上班，學院適用的停課安排請按校曆自行加入。內置表是隨程式發放的快照，沒有連網自動更新。

CSV欄位：`date,end_date,name,start,end,enabled`。`end_date`選填，留空為單日；舊版CSV可直接匯入。日期範圍包含起訖，最長367個曆日。`date`用`YYYY-MM-DD`；時段`HH:mm`，留空為全天，結束可用`24:00`。逗號可用CSV雙引號。介面可下載範本。

ICS支援單次全天事件、跨日事件及部分時段事件；全天DTEND依標準為不包含結束日。支援UTC轉UTC+8、澳門／香港／台北／上海時區及浮動本地時間，秒數須00。**循環規則、例外日期、其他時區會拒絕整份匯入**，請先轉為逐日CSV。匯入有預覽及格式驗證，不會靜默忽略不支援事件。相同日期＋名稱＋起訖不重複新增。

## 校內儲存與協作

[Share Drive／OneDrive及校內同步方案](docs/CAMPUS-SHARING.md)。本版沒有外部資料庫、登入或跨電腦同步。共用HTML不會共享瀏覽器資料。OneDrive是否在校內要由IT確認部署，不能由名稱判斷。

資料只寫入此瀏覽器；JSON／Excel由你手動匯出。若儲存至OneDrive同步目錄，匯出檔案仍可能上雲。直接開啟file://時儲存位置依瀏覽器及檔案路徑；移動／更新程式前請備份。請勿多視窗同時排課；跨視窗更新提示不是交易鎖。

公開GitHub只放程式及說明，**請勿提交真實課表備份或內部資料**。
