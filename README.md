# 金融學院排課系統 v2.0（離線版）

按 CityU-FOF 原有排課介面改良。毋須安裝、毋須帳戶；下載整個倉庫 ZIP，解壓後雙擊 `index.html`。**請保留同一資料夾內的 styles.css、scheduler-core.js、vendor 資料夾，勿只下載 HTML。**

## 使用步驟

1. 在舊系統按「備份」下載 JSON（資料不會隨程式自動搬過來）。
2. 在新版按「還原」，選擇舊 JSON。匯入會取代目前資料；可撤銷。
3. 按「檢查」查看舊資料內既有的班級、教師或課室衝突。
4. 拖曳待排拼圖到所屬班級課表；亦可先點選卡片，再點時間格。點待排卡片會自動切換至該班級。
5. 已排課可拖到另一格、拖回左方待排池，或按 × 移回待排池。左方 × 為永久刪除；可撤銷。
6. 卡片按「編輯」可填課室、修改科目或教師；只影響該節。已排課可按鎖頭鎖定／解鎖。
7. 定期按「備份」。Excel 是報表，不能當作完整還原備份。

## 教學時數口徑（務必先看）

這是**每週重複課表的學期推算**，並非已實際完成授課的紀錄。

- 預設15教學週，每學時50分鐘。例：每週2節×75分鐘×15週÷50＝45學時＝37.5鐘點小時。
- 在「設定」按學院規定修改。此預設是推算示例，並非已核實的學院政策。
- 「已排學時」按已排課節計算；明確確認的合班教師只計一次，班級課表仍各自保留。
- 「預計上限」＝已排學時＋待排班級節次×75分鐘×週數÷每學時分鐘。待排尚未合班，因此只是上限；排完合班後可能下降。
- 原版同時段重疊不會自動當作合班。先移回待排池，重新安排並確認合班。
- 合班課節要變更時間或教師／課室，先逐班移回待排池，再重新安排。已鎖定課節須先解鎖。
- 全部週一至週日、1至8節。未涵蓋假期、停補課、單雙週、不同週範圍、共同授課或不同課節時長。

## 儲存及共享

每部電腦／瀏覽器各有自己的資料；傳送程式 ZIP 不會帶走你的課表。請另外匯出／匯入 JSON。直接開啟 `file://` 的瀏覽器儲存行為可因瀏覽器及檔案位置不同，移動資料夾前務必備份。

同來源多視窗修改時，較舊視窗會停止自動儲存並提示先備份再重新載入。這項保護**不是跨電腦同步**，亦不是伺服器交易鎖；不要同時開多個視窗排課。

GitHub 倉庫公開，僅存放程式及說明；**不要將真實備份、內部教師安排或學生資料提交到公開倉庫。** 程式目前不會上傳資料，也沒有多人登入或線上同步。

## 下一階段優先功能

1. 教師不可上課時段、教室容量／類型、連堂及午休／晚課規則。
2. 學期／方案分開儲存、方案比較、操作紀錄。
3. CSV／Excel課程匯入、科目／教師／課室資料字典，避免名稱不一致。
4. 小型多人同步：登入、學院／學期權限、版本衝突拒絕、修改歷史，再加入即時通知。
5. 排課建議或求解器：先定義硬性／軟性限制，再考慮FET或Timefold；此版本沒有自動排課求解器。

## 開發及驗證

核心測試：`node --test tests/core.test.cjs`（Node.js 18+，不需安裝依賴）。

DOM整合測試：`npm install`，然後 `npm test`。日常離線使用不用安裝Node。

樣式已編譯。修改介面後重建：`npx --yes tailwindcss@3.4.17 -i input.css -o styles.css --content index.html --minify`。

第三方授權及版本見 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。未複製UniTime、FET或Timefold程式碼；研究參考與本次實作分開。
