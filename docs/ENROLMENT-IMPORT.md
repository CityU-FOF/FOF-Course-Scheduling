# 選科系統Excel匯入（v3.4）

## 操作

1. 先備份JSON。學期初可只建立科目及安排時間，不必先填一般課室／人數。
2. 教務處指派課室、選科後，從選科系統匯出課程表，開啟「教室資料 → 匯入選科系統Excel」。
3. 核對來源學期代碼與目前學期相同；表內多個學期代碼會拒絕，需分開匯出。
4. 預覽勾選要更新的科目班級。預設依科目編號、課程、年級及科目名稱尾部班別配對。未配對可在同編號的現有班級中選擇；本功能不建立新課節。
5. 選「只看需核對項目」，檢查來源總碼班次與名稱班別不同、教師差異、多課室及來源錯誤。總碼內班次可能是開班序號，例如名稱I班而總碼A；不因此自動改成A班。
6. 選擇更新人數／課室／容量。多課室逐星期節次確認，不能判定就留空保留原值。容量資料在下方展開核對，與既有值不同預設不覆寫。
7. 確認更新；整次匯入可撤銷。需要時切換到「教務處指派／選科後核對」階段，再查看排課檢查及容量壓力。最後備份JSON。

## 人數口徑

讀取「正選人數」，不讀取上課名額、保留人數或等待人數。0是已知0人，與未填分開。

`科目名稱 - BAE105-B`為主班，`科目名稱 - BAE105-跨課程併1B`指向大一B班。主班24＋跨課程2＝26；本系統各個BAE105-B課節更新為26人，**不新增跨課程課節，不增加教師節次**。跨課程列的必選修性質不會把本院主班改為選修。

常見跨課程科目：BAE101、BAE102、BAE103、BAE104、BAE105、BAE106、BAE201、BAE205、BAE206、BAE207。其他明確跨課程標記仍可分析，但須人工勾選核對。

主班與跨課程列的教師、時段及課室須一致。缺主班、缺正選人數、相互矛盾資料不猜數值。相同科目總碼的完全重複列只計一次；相同總碼內容不同會阻擋有關項目。重複匯入以來源重新計算的總人數**取代**舊值，不加到舊總數。

## 課室與時間

來源有明確單一課室時，可依匹配的時段補入；待排課節亦可補入單一課室。來源同時列多個課室但沒有逐節配對，不能假設按文字次序一一對應，須人工逐時段選擇。未匹配來源時段的已排課節保留原課室；匯入不調動任何星期／時間。多課室的待排節次保留原值，待安排到來源時間後再匯入。

Golden Dragon前綴`GDC-`作為比對別名，例如`GDC-G2106`與`G2106`。若本系統已有相同別名的教室登記，沿用既有名稱，避免新增另一間。其他校區前綴保留。

容量只從**單一課室**的來源列提取；多個課室共用一個容量值無法確定每間容量。來源同室容量互相矛盾或與現有容量不同，預設不勾選，核對後才輸入確認值。

官方選科結果可能已超容量或存在衝突；匯入保留實際資料，再於本系統提示風險，不會刪除原課節。若所選班級含鎖定課節，先解鎖再重新匯入。預覽後資料有變動則須重新預覽。

## 本機與格式

支援`.xlsx/.xls`，最多10MB；工作表需包含科目總碼、科目名稱、正選人數、教室節次館別等匯出欄位。採用已隨附的SheetJS，不需網絡或API，資料不離開瀏覽器。只讀Excel現有值，不執行公式。

不會從這份課程匯出推測期末考核形式，也沒有學生姓名／學號清單可用來產生座位表。考試系統整合不在本輪範圍；期末形式為報告／論文亦可能另設期中考試，未把兩者綁定。
